# Electrical Engineering Learning Platform

A lightweight, browser-based collection of **electrical engineering learning resources**.
The page organizes circuit-analysis references, soldering tutorials, virtual-lab links, and quizzes.

> **Status:** Educational project / curated links. This is not a professional-grade circuit simulator, and it does not host its own courses, lab engine, enrollment system, or backend.

## Features verified in the source

- Navigation to Courses, Tutorials, Labs, and Quizzes sections.
- Resource cards generated by `resourcemanager.js`, including external references and embedded YouTube videos.
- A client-side keyword search that filters generated cards.
- A feedback form that prepares an email in the visitor's email application, plus a GitHub Issues fallback. **No form data is collected on a server.**
- Responsive styles in `styles.css` and a basic accessibility-oriented document structure.

Some educational resources belong to third parties; their availability and content are not controlled by this project.

## Run locally

Clone the repository:

```bash
git clone https://github.com/Tyler-Keesee/Electrical-Engineering.git
cd Electrical-Engineering
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

The site is static HTML/CSS/JavaScript. No API keys, accounts, server-side database, or npm dependencies are required for the learning resources.

## Tests

With Node.js 22 or newer:

```bash
node --test tests/*.test.mjs
```

GitHub Actions also runs a headless-Chrome resource-rendering smoke test for the site.
These tests check fundamental page functionality, **not** every external resource, device, or browser.

## Repository structure

| File | Purpose |
| --- | --- |
| `index.html` | Page sections and accessibility labels |
| `styles.css` | Site layout and visual design |
| `resourcemanager.js` | Curated resource definitions and DOM rendering |
| `main.js` | Search interactions and email feedback |
| `tests/site-smoke.test.mjs` | JavaScript and markup checks |
| `.github/workflows/site-smoke.yml` | CI checks, including browser rendering |

## Scope and limitations

The lab section links to an external interactive circuit-construction environment. Quiz and video links are also external and may change. No user enrollment or in-page lab backend has been implemented. This repository should not be used as electrical safety or certification guidance.
